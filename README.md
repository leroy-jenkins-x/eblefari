# eblefari · накорми пати

Милая и безумная интерактивная история на русском: двое влюблённых, две большие и две маленькие собаки, три змеи, ящерица Антарас, растения на продажу и гильдия Lineage 2. В финале — процветающий бизнес, большое состояние и всё тот же пушистый беспредел.

## Что внутри

- Шесть глав и 36 сюжетных сцен, примерно на 6 минут неспешной игры.
- Одиннадцать решений и 2048 комбинаций выбора. Все пути заканчиваются счастливо.
- Шесть маленьких занятий: уход за питомцами за пять нажатий, посадка растений, фотосъёмка с собакой, рейд, упаковка заказов и обустройство дома.
- Восемь биографий питомцев и случайные «виззи», «пиззи», «шмиззи»: маленькие реплики в правом верхнем углу с плавным затуханием.
- Оригинальные векторные иллюстрации семьи, анимация, необязательные звуки, имена героев на выбор, отдельная картинка для каждой главы.
- Автосохранение прогресса в этом браузере и поддержка клавиатуры, сенсорного экрана и режима уменьшенной анимации.

Игра рассчитана на вертикальный экран телефона. Время зависит от чтения и изучения питомцев. Никаких обязательных таймеров, аккаунтов и платежей. Основные события занимают около 5–7 минут. Все денежные суммы — выдумка.

Персонажи нарисованы по фотографии пользователя: героиня со светлыми цветными дредами в тёмной футболке и лысый бородатый герой в жёлтой футболке. Оригинальное фото не публикуется. Имена Эбле и Энжи можно поменять на начальном экране.

Игра помещается в вертикальный экран без прокрутки: длинные сцены разделены на короткие страницы, короткие решения показаны вместе со сценой, в уходе за питомцами одновременно видны три мордочки. Кнопка назад возвращает на предыдущую страницу текущей сцены, не отменяя решения. Старые сохранения сохраняются. Кнопка «Начать заново» доступна в истории, мини-играх и финале; сброс требует подтверждения.

## Запуск

Это статические HTML, CSS и JavaScript без сборки и установки зависимостей. Для локального запуска:

```sh
python -m http.server 8000
```

Откройте `http://localhost:8000`. Файлы используют JavaScript-модули, поэтому прямое открытие через `file://` не поддерживается. Шрифты Google необязательны: если они недоступны, используются системные.

## Проверки

Node.js 20 или новее:

```sh
npm run check
npm test
```

Проверки охватывают все развилки, состав семьи, порядок глав, сохранения, безопасность пользовательских имён, границы показателей и полное прохождение через настоящие обработчики игры. Этот тест не заменяет проверку верстки в браузере.

## GitHub Pages

В репозитории откройте **Settings → Pages → Deploy from a branch → main → /(root)** и сохраните. Pages опубликует `index.html` и связанные файлы. Следующие коммиты обновляют сайт. Файл `.nojekyll` оставляет проект без сборки.

Другой вариант: **Settings → Pages → GitHub Actions**. В комплекте есть `.github/workflows/pages.yml`, который проверяет код и публикует только игровые файлы.

## Файлы

- `story.js` — русский сюжет, главы, решения и последствия.
- `art.js` — питомцы и оригинальная векторная графика.
- `app.js` — интерфейс, мини-игры, диалоги, звук и сохранение.
- `engine.js` — работа с состоянием и данные заданий.
- `layout.js` — разбиение текста на короткие страницы без потери предложений.
- `styles.css` — оформление вертикального экрана и анимация.

Все игровые действия выполняются на устройстве пользователя. Прогресс исчезнет при очистке данных браузера. Проект не связан с создателями Lineage 2 и не использует графику или музыку из игры.
